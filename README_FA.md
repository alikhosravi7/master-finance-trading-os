# MASTER FINANCE TRADING OS — نسخه اولیه موبایل

## نصب روی اندروید
این پروژه یک وب‌اپلیکیشن قابل نصب (PWA) است. برای نصب واقعی باید فایل‌ها روی یک هاست HTTPS قرار بگیرند؛ باز کردن مستقیم `index.html` از حافظه گوشی، نصب PWA را فعال نمی‌کند.

1. پوشه پروژه را روی یک هاست HTTPS یا سرویس استاتیک مانند GitHub Pages / Netlify منتشر کنید.
2. آدرس سایت را با Chrome اندروید باز کنید.
3. از منوی سه‌نقطه Chrome گزینه Install app یا Add to Home screen را انتخاب کنید.
4. آیکون Master Finance روی صفحه گوشی ظاهر می‌شود.

## امکانات نسخه ۱
- داشبورد موبایلی با تم تیره و طراحی شیشه‌ای
- نوار قیمت رمزارزها با فعال‌سازی دستی مدیر (Binance public API)
- چارت TradingView برای BTC/USDT
- پنج بخش پروفایل، بک‌تست، ترید، ژورنال و استراتژی
- ثبت معاملات با Entry / SL / TP / Risk / R:R
- ثبت نتیجه معاملات و محاسبه وین‌ریت ساده
- ذخیره محلی داده‌ها در مرورگر

## ورود مدیر و محدودیت امنیتی
در اولین ورود به پروفایل، رمز مدیر را ایجاد کنید. سپس گزینه قیمت آنلاین رمزارزها را فعال کنید. این نسخه کاملاً سمت کاربر است؛ رمز فقط روی همان مرورگر ذخیره می‌شود و کنترل دسترسی واقعی چندکاربره یا امنیت سروری نیست. برای انتشار عمومی یا ذخیره اطلاعات حساس، باید احراز هویت سمت سرور، پایگاه داده و مدیریت نشست اضافه شود.

## داده‌های بازار
- قیمت رمزارزها: Binance public market API
- نمودار: TradingView embed
- طلا و فارکس: فعلاً نمایشی/غیرفعال؛ برای داده زنده پایدار باید سرویس داده بازار و API key معتبر متصل شود.
- اتصال بروکر و ارسال سفارش واقعی: در این نسخه وجود ندارد.

## نکته
این نسخه MVP رابط و ثبت اطلاعات است، نه سامانه اجرای سفارش. قبل از استفاده عملیاتی، بک‌آپ داده و تست روی دستگاه هدف انجام شود.
